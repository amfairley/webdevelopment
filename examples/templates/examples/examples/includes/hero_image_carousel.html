In this example we have a carousel that can be used for the hero section of the website. It contains a website title and welcome message whilst cycling through images with a slight zoom effect.

This is achieved by placing the text on top of a carousel of images allowing the site title and message to be continually visible to the user whilst the carousel automatically cycles in the background or is manually progressed.

This uses Bootstrap 5 and requires the bootstrap JavaScript to run the carousel, so ensure you have that set up correctly.
